# Budovsky · дашборд Яндекс Директа

Онлайн-дашборд рекламных кампаний клиники доктора Будовского (Санкт-Петербург): KPI Директа, кампании, заявки с сайта, работы по сайту. Есть выбор периода статистики.

## Как устроено

- `index.html` — страница дашборда.
- `data/*.json` — данные. Каждая строка помечена месяцем в поле `period` (`2026-10`).
- `assets/dash-shim.js` — загрузка данных и отрисовка блоков; `assets/theme.css` — цвета и шрифты (светлая и тёмная тема).
- `server.js` — статический сервер без зависимостей.

Сейчас в данных один месяц: октябрь 2026 (PDF-отчёт и кабинет Директа). Показатель «Отказы» не учитывается; Доход, ДРР и ROI не выводятся.

## Как добавить месяц

Добавьте строки с новым `period` во все четыре файла:

1. `data/totals.json` — строка «Итого» из кабинета: `period`, `label` (например «Ноябрь 2026»), `dates` («1–30 ноября 2026»), `spend`, `impressions`, `clicks`, `conversions`, `cpa`, `cpc`, `ctr`, `cr`, `budget_week`. По этому файлу строится список периодов.
2. `data/campaigns.json` — по строке на кампанию.
3. `data/leads_service.json` и `data/leads_source.json` — заявки с сайта по услугам и источникам.

Блоки с текстом про конкретный месяц (сбой Директа в октябре, работы по сайту) помечены `data-period="2026-10"` и показываются только для этого месяца.

## Запуск

```bash
npm start          # http://localhost:3000
```

## Деплой на Railway

New Project → Deploy from GitHub repo → выбрать этот репозиторий. Railway сам запустит `npm start`, порт берётся из `PORT`. Затем Settings → Networking → Generate Domain.
